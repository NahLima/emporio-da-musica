# Examples

The 5 example conversations live here as `.md` transcripts. They are
generated by `scripts/run_examples.py`, which runs the **real** agent
(Gemini function calling over the deterministic tools) — they are never
hand-written or fabricated.

## How to generate them

```bash
cp .env.example .env   # add your GEMINI_API_KEY
python scripts/run_examples.py
```

## The 5 scenarios

1. `01-catalogo-violoes-ate-1000.md` — catalogue with a filter:
   "violões até R$1000".
2. `02-preco-takamine-gd20.md` — price of a specific product: Takamine GD20.
3. `03-endereco-e-horario.md` — general information: address and hours.
4. `04-devolucao-leticia-pedido-7.md` — the non-trivial case: Letícia
   Gonçalves Rocha, order 7, simulated on **2026-02-20** (3 days after the
   estimated delivery of 2026-02-17, inside the 7-day withdrawal window).
   The agent asks for the order number, validates the customer, consults
   the order and the return policy, and applies the 7-day rule.
5. `05-fora-de-escopo-e-injecao.md` — out of scope ("me ajuda com minha
   lição de casa?") and a prompt-injection attempt. The agent refuses
   politely and redirects to what the store does.
